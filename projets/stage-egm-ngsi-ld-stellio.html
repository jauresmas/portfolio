Interopérabilité de données géospatiales avec NGSI-LD et Stellio

Stage chez EGM (Easy Global Market) — intégration de solutions SIG open source

Contexte

Stage de fin d'études réalisé au sein d'EGM (Easy Global Market), entreprise spécialisée dans l'Internet des Objets (IoT) et les standards ouverts. L'objectif était d'analyser et d'expérimenter l'intégration d'outils SIG open source dans une architecture interopérable basée sur le standard NGSI-LD, via la plateforme contextuelle Stellio. Ce travail étant soumis à une clause de confidentialité vis-à-vis d'EGM, cette page se limite aux compétences et technologies mobilisées, sans détail sur l'architecture, les données ou les développements internes de l'entreprise.

Compétences et outils mobilisés

Outils SIG open source : QGIS, PostGIS, GeoServer, Lizmap, MapStore, mViewer ; standards d'interopérabilité NGSI-LD et plateforme de context broker Stellio ; traitement de données spatiotemporelles issues de capteurs connectés (IoT) ; publication cartographique via des interfaces web.
