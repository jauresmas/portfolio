+# Portfolio de Jaurès DAA-HINGBANON
+
+Ce dépôt contient le code d'un site web statique servant de portfolio personnel. Le projet est principalement écrit en **HTML**, **CSS** et **JavaScript** et propose plusieurs animations grâce à **Particles.js**.
+
+## Structure du projet
+
+- **index.html** : page d'accueil et sections (projets, portfolio, compétences, formations, contact).
+- **portofolio.css** : feuille de style utilisée pour la mise en page et les effets visuels.
+- **portofolio.js** : logique JavaScript assurant les animations du logo, le changement d'image au survol et l'initialisation de Particles.js.
+- **particles.min.js** : bibliothèque gérant l'arrière‑plan animé.
+- **img/** : répertoire contenant l'ensemble des images du site.
+
+## Utilisation
+
+Aucune étape de build n'est requise. Pour consulter le portfolio, ouvrez simplement le fichier `index.html` dans votre navigateur.
+
+Le site présente différents projets de géomatique et met en avant les compétences de son auteur à travers une interface responsive et animée.
